# 调研：给逝去的亲人一个"美好的虚拟家园"

调研日期：2026-10-14。想法：每年在固定的日子"去看看"亲人，看到 TA 在一个美好的虚拟环境里生活，给 TA 送东西、说说话，并帮 TA 实现生前没能实现的愿望。

## 一、结论

**这个需求是真实存在的，而且非常古老。** 烧纸扎就是在给逝者"送房子、送车、送手机"，让 TA 在另一个世界过得好。年轻人现在会给逝去的亲人烧纸扎的 iPhone、Switch 和汽车。越南人的祭品里也出现了"给亡灵的手机"。墨西哥的亡灵节会在祭坛（ofrenda）上摆出逝者最爱的食物。你的想法本质上是把这件事数字化，并让它"活"起来。

**现有产品的形态很落后。** 网上祭扫的规模不小：2020 年清明节当天，网络祭扫平台服务 1336 万人次；2022 年清明，全国开通网络祭扫平台 1543 个。但它们大多是静态纪念页，点蜡烛、献虚拟花、买虚拟礼物（海外常见定价是虚拟花 $4.99、蜡烛 $2.99）。"元宇宙墓园"和 Somnium Space 一类的产品很小众，而且过去十年有多家免费纪念网站关停，基本没有提前通知家属。**还没有人做出"一个会随着时间生长、承载愿望、全家共同照料的家园"。**

**最大的风险是"把愧疚变成收费点"。** 学界已经批评网络墓园把纸扎变成可购买的数字商品，把祭祀变成"可控、可商品化的哀悼劳动"。一旦做成"妈妈很孤单，送她一份礼物 ¥6"这类付费机制，就会同时踩到伦理、口碑和监管（诱导消费）三条线。

**它和 Kinsong 契合度很高，而且比天天聊天更健康。** 按节日、按年度"去探望"，本来就是有边界的仪式，正好对冲我们一直在防的"过度依赖"。建议把它做成 Kinsong 的一个模式（暂名 **Garden / 思念园**），不另起一个产品。

## 三、它和现有产品的不同

| | 网上纪念页 / 云祭扫 | 元宇宙墓园 | AI 复原 / 聊天 | **思念园（提案）** |
| --- | --- | --- | --- | --- |
| 形态 | 静态页面 | 3D 场景，需要 VR 或 PC | 对话或视频 | 手机上一个温暖的插画风小世界 |
| 随时间变化 | 否 | 少 | 否 | **是**：每次探望种一株花，几年后长成花园 |
| 节奏 | 清明一次 | 随时 | 随时（有依赖风险） | **按纪念日**：生日、忌日、清明、中元、冬至、中秋、亡灵节、Memorial Day |
| 愿望 | 无 | 无 | 无 | **愿望清单**：家人写下 TA 未竟的心愿，生成标明"想象"的明信片或小短片 |
| 全家参与 | 弱 | 弱 | 个人 | **共享**：兄弟姐妹能看到彼此留下的花和信 |

## 四、产品形态建议（作为 Kinsong 的一个模式）

1. **家园。** 风格是温暖的插画，**不追求照片级写实**，避免"恐怖谷"，也避免暗示"这就是真实的来世"。场景由 TA 生前喜欢的东西构成：从聊天记录和家人写的回忆里提取（"爱养花""最爱的藤椅""阳台的茉莉"）。已有的头像组件可以放进场景里。
2. **纪念日日历。** 家人选择要过的节日：清明、中元、冬至、春节、中秋、Chuseok、Tết、亡灵节、Memorial Day、生日、忌日。到了日子推送一条温和的提醒："今天是妈妈的生日，要去看看她吗？" **平时不推送。**
3. **心意，而不是商品。** 每次探望可以：种一株花（花园随年份生长，这是全家共同的积累）、写一封信、"做"一道 TA 的拿手菜（来自回忆里的菜谱）、放一首 TA 爱听的歌。**全部免费，没有稀有度，没有"送得多 TA 更开心"。**
4. **愿望清单。** 家人写下"妈妈一直想去看京都的樱花""爸爸想看我结婚"。在相应的日子，用 TA 的口吻生成一张明信片（有声音授权时可以朗读），画面明确标注**"想象中的画面"**。不生成任何会被误认为真实照片的影像。
5. **一年一次的"来信"。** 每个纪念日，TA 用自己的口吻"回"一封短信，内容只基于真实回忆，沿用现有的安全规则。这比天天聊天更克制，也更有仪式感。
6. **家人共享。** 全家一起照料同一个花园，但要端到端加密同步，或者默认只在本机。可以设置"谁能看到我的信"。
7. **告别。** 保留"把花园定格成一本纪念册（PDF/打印），然后删除"的选项。

## 五、商业模式：一条红线，几种体面的收入

**红线：** 不卖虚拟祭品，不做抽卡或稀有道具，不用"TA 在等你""TA 很孤单"这类话术催付费，不在纪念日推付费内容。

**体面的收入：**
- 在 Kinsong 一次性买断里加上"家庭共享花园"（需要加密同步服务，可以单独收年费，但停费后**本地内容永远保留**）。
- **实体服务，同时也是渠道：** 在纪念日把真花送到真实的墓地或骨灰堂（与花店或墓园合作）；每年打印一本纪念册（当年的信、花园、愿望明信片）。
- 面向殡仪馆、墓园、临终关怀机构的 B2B 授权：他们本来就在做"云祭扫"，需要一个更好的产品。

## 六、风险

| 风险 | 应对 |
| --- | --- |
| 愧疚营销、诱导消费 | 第五节的红线写进产品原则和代码审查清单 |
| 宗教与文化冲突（天堂、轮回、伊斯兰教对形象的禁忌…） | 不说"来世"，用"家园、花园、纪念空间"；场景和节日由家人选择；可以完全不出现人物形象 |
| "TA 在那边过得很好"变成逃避 | 有节奏的纪念日加克制的提醒；连续高频访问时沿用现有的关怀提示 |
| 想象的画面被当成真实记忆 | 所有生成内容永久标注"想象"；不生成写实照片；不做"P 进婚礼照片"这类功能 |
| 平台关停 | 本地优先、可导出纪念册，正好回应"纪念网站说关就关"的问题 |
| 法规 | 沿用 Kinsong 的同意和撤回机制。生成"TA 去了京都"的画面属于逝者肖像的使用，同样要经过家人和遗产执行人同意 |

## 七、北美市场的切入点

- **目标人群：** 有祭祖传统的移民家庭，包括华人（清明、中元、冬至）、越南裔（Tết、忌日）、韩裔（Chuseok、Seollal 茶礼）、墨西哥裔（亡灵节）。他们往往**离墓地很远**（墓在故国），"去不了现场"是刚需。
- **时间窗口：** 亡灵节 2026-11-01/02（太近，只够做访谈和概念测试）；**清明 2027-04-05**（适合发布第一版）。
- **验证方法（下一步）：**
  1. 访谈 15–20 个上述家庭，重点问：会不会每年用？最在意什么？哪种付费方式会被反感？
  2. 做一个可点击的原型（花园、日历、愿望明信片），在访谈中给他们看。
  3. 对比两种方案的反应：A "TA 的家园"（有人物），B "纪念花园"（没有人物）。

## 八、欧美主流用户（非移民家庭）

### 结论

**需求同样存在，但"送东西"和"TA 住在那里"这两个核心要换说法。** 欧美没有烧纸扎、给逝者送用品的传统。他们的心意是**花、蜡烛、信、捐款、种树**。"天堂"的说法在美国很普遍，在欧洲弱得多。所以在欧美应该把它定位成**"一个可以去探望 TA 的地方"**（memorial garden），而不是"TA 在那边的家"。"实现愿望"最好的说法是**"替 TA 完成心愿清单"**（bucket list），而且尽量在现实里完成。

### 证据

| 维度 | 发现 | 对产品的含义 |
| --- | --- | --- |
| 对来世的信念 | 美国约 67% 的人相信天堂（2020 年世界价值观调查），但无宗教信仰的人群在增加，整体比例在下降（Pew 2025）。欧洲明显更低：英国约 35%、挪威 34%、丹麦约 18%。 | 美国可以提供可选的"天堂"主题；欧洲默认用"纪念花园"，不出现来世意象 |
| "天堂里的生日" | "Happy birthday in heaven" 已经是美国社交媒体上普遍的仪式（只有博客层面的描述，没有学术研究）。 | 生日、忌日（英语里有人叫 *angelversary*）是天然的探望日 |
| 欧洲扫墓 | 11 月 1–2 日（诸圣节、万灵节）全家去扫墓。法国、比利时、意大利、匈牙利送花；波兰、奥地利、克罗地亚、罗马尼亚点蜡烛（波兰民间相信蜡烛能为亡灵照路）。匈牙利 11 月 1 日是全年最大的出行日，可以和美国感恩节相比。 | 心意的形式就是**花和蜡烛**，按国家默认不同 |
| 对逝者说话 | 源自日本的"风之电话"（一部断线的电话亭，用来对逝者说话）在北美迅速扩散：My Wind Phone 统计美国已有 70 多座；2026-04 的一则报道说北美已有 260 座。 | "写信、说话"本身就是需求，不一定需要 AI 回答 |
| 现实与线上的连接 | Find a Grave 的纪念页加了"送花"按钮（与 BloomBridge 合作），送到后拍一张墓前的照片发给顾客。我没找到美国有成型的"定期送花到墓地"订阅服务；澳洲有墓园提供定期送花。 | **空档**：每个纪念日把真花送到真实墓前，花园里同步出现这束花并附上照片 |
| 种树 | Better Place Forests 把骨灰安放在受保护森林里的纪念树下，起价约 $4,900（2021 年数据）。 | 每次探望"种一株花"在欧美很好理解，可以与真实种树的公益机构合作 |
| 游戏里的纪念 | 《魔兽世界》里有玩家纪念碑、为已故玩家做的纪念任务线。VRChat 上有虚拟形象葬礼；研究发现年轻人认为线上纪念很自然，年长者更偏好私密、庄重、实体的仪式。 | 年轻用户可以接受"活"的世界；年长用户需要庄重、安静的设计 |
| **"帮 TA 完成心愿再告别"** | 游戏《Spiritfarer》讲的正是这件事：玩家帮亡灵完成生前心愿，再送 TA 们离开。CHI 2021 的研究发现，玩家的哀伤体验与 Stroebe 和 Schut 的"双过程应对模型"高度吻合；另一项研究发现丧亲玩家会"回忆往事""从逝者的角度看问题"。 | **这是你这个想法在西方最有力的旁证**：完成心愿的叙事，对哀伤有正面意义 |
| 宠物 | 西方的"彩虹桥"（Rainbow Bridge）本身就是一个"TA 在那边过得很开心"的虚拟乐园想象。宠物纪念市场的估算从 12 亿到 63 亿美元不等（口径不一、来源偏弱），北美约占 42%。 | **最佳切入点之一**：情感真实、没有肖像权和生物特征法规的问题、文化上完全接受"在那边很快乐" |

### 欧美版的产品调整

| 东亚版 | 欧美版 |
| --- | --- |
| "TA 的家园" | **"Memorial Garden"**，可选"Heaven"主题（美国宗教家庭）或"Rainbow Bridge"（宠物） |
| 送一道菜、烧一封信 | **点一支蜡烛、放一束花、写一封信、录一段话**（风之电话式，可以不需要 AI 回应） |
| 清明、中元、冬至 | **生日、忌日、母亲节/父亲节、圣诞节（空椅子）、感恩节、Memorial Day、万灵节、亡灵节** |
| 想象的明信片 | 同样保留，**另加"现实心愿清单"**：家人在现实中替 TA 完成（去巴黎、撒骨灰、跑一次马拉松），拍照放进花园 |
| 卖实体服务 | **真花送到真实墓前并拍照回传**，以TA 的名义**捐款或种树**（与公益机构合作，收入透明） |
| 全家私下共享 | 增加**"邀请朋友留言"**的选项（欧美有在纪念页公开悼念的文化），默认关闭 |

### 建议的欧美切入顺序

1. **宠物版**：风险最低、接受度最高、决策快。可以单独上架，比如"Kinsong for Pets"。
2. **"替 TA 完成心愿"加纪念日送花**：这是欧美最差异化的部分，也是最自然的收入来源。
3. **人物家园**：在前两步积累了信任和口碑之后再推。人物化身在欧美争议最大（参考 2wai 的舆论反弹）。
