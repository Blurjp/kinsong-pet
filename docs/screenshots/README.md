# Screenshots

Captured in the iOS Simulator (iPhone 17, iOS 26.2) and, for cut-outs, on a Mac running the app's own code, while building the features in PR #1. Test pets are freely licensed photos and videos from Wikimedia Commons (see `app/assets/garden/CREDITS.md` and `app/assets/scenes/CREDITS.md` for the scenes), not anyone's real pet.
